Two Filters 1.1, a paired filter plugin using the surge filter library.

New in 1.1:

- An envelope follower modulation source, listening to the main input or a new stereo sidechain
  on L, R, Mid or Side, with attack, release and gain. It routes to both filters' cutoff and
  resonance, pre gain, filter blend, mix, feedback and noise, with a live trace of what it hears.
- The audio recovers by itself if it ever goes bad, and stays stable under extreme modulation.
- CLAP preset discovery, so factory and user presets show up in your host's browser.
- CLAP remote controls pages for the filters, routing, step LFOs and envelope follower.
- Per-patch automation smoothing.
- The Cascade SVF filter model.
- 175% and 200% zoom, and an audio and MIDI settings menu in the standalone.
- Linux .deb packages for x64 and aarch64.

Download the file for your os and run the installer (mac) or install the files (lin/win) included. Have fun!
